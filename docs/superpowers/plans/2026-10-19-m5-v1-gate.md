# M5 v1.0 Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and run the pre-registered, capability-matched live recovery study (Claude + Codex) that decides v1.0 GO / NO-GO / INCONCLUSIVE.

**Architecture:** Add a Codex CLI response transport beside the existing Claude Code one; add pure verdict functions over the existing `aggregate_repeated` summary; add a calibration helper (uncrashed `run_reference` runs); compose the live chain task with a torn `send-report` effect per crash step so every cell scores C1 and C3; freeze protocol + code hashes before any live call; run per model; compute the gate.

**Tech Stack:** Python 3.12 stdlib, pytest, existing `cairn.eval` harness, `claude` CLI, `codex` CLI 0.162.x.

**Spec:** `docs/superpowers/specs/2026-10-19-m5-v1-gate-design.md`

## Global Constraints

- Branch: all work on `milestone-5-v1-gate`; master merges via PR (branch-per-phase).
- No hardcoded harness (ADR-0007/0010): providers are injected config; chain task, baselines, harness and `TerminalWorld` are unchanged.
- Honest results (ADR-0009): negatives recorded; every verdict reported whichever way it falls.
- Secret hygiene: no keys printed, staged or committed (the CLIs use their own auth).
- Stdlib only; no new dependencies.
- Calibration: `R_cal = 10` uncrashed runs; eligible iff `calibration_rate >= 0.80` AND at least 9 of 10 runs completed without transport error.
- C1 (capability-matched): B0 and B3 fired, B0 ≥ 1 success; `B3.success_rate >= calibration_rate - 0.10` and `B3.success_rate >= B0.success_rate`; `B3.tax.max < B0.tax.min` (success-conditioned); `B3.no_regression.mean >= B0.no_regression.mean`.
- C3 (live): B3 has 0 effect duplicates in every fired cell; B0 has ≥ 1 duplicate across its cells.
- Gate: INCONCLUSIVE if either model is ineligible or > 10% of planned study cells for either model were lost to transport errors or rate limits; GO if C1 and C3 supported on both models; NO-GO otherwise.
- Study per model: chain `n=6`, crash steps `k ∈ {2, 3}`, baselines B0 (ColdRestart) and B3 (RGR), 8 repeats → 32 planned cells.
- Models: Claude `sonnet` via `claude_code`; Codex default model via `codex_cli` (exact id recorded at run time).
- Thresholds are never changed after live data is seen; a change needs a new pre-registration and invalidates earlier live data.
- The existing strict `verdict_c1` is kept unchanged and reported alongside.
- Test command: `python -m pytest -q` from `D:/project-unknown`.

## Review Focus

- Codex writes no reply file, or an empty one (e.g. it attempted a tool call that the sandbox refused) → transport raises `LiveModelConfigError`, never returns "" as an action. Test in Task 2.
- A transport error during calibration → counted as an incomplete run; 2 errors make the model ineligible even if every completed run succeeded. Test in Task 3.
- The torn effect not actually duplicating under B0 (e.g. effect step ≠ crash step) → C3 must be NOT supported, not vacuously supported. Test in Task 4.
- A model whose cells never fire (zero B0/B3 cells) → C1 not supported and the gate is not GO. Test in Task 4.
- Pre-registered file changed after freezing (including line-ending churn) → the study refuses to start with the mismatching path named. Test in Task 6.

```python
def codex_cli_transport(
    *,
    model: Optional[str] = None,
    command: str = "codex",
    timeout: float = 120.0,
    run: Optional[Callable[..., object]] = None,
) -> Transport:
    """Use an authenticated local Codex CLI as a no-tools response transport.

    Each call runs ``codex exec`` ephemerally in a fresh empty temp dir under the read-only
    sandbox, with the same system instruction and reply schema as the Claude Code transport, and
    returns only the final reply. Cairn executes the parsed action in ``TerminalWorld``; Codex
    never sees the benchmark checkout. The model ids Codex reports are kept in
    ``observed_models`` so a run can record the exact model used.
    """
    runner = run or subprocess.run
    observed: set[str] = set()

    def complete(prompt: str) -> str:
        with tempfile.TemporaryDirectory(prefix="cairn-codex-") as tmp:
            schema = os.path.join(tmp, "schema.json")
            reply_path = os.path.join(tmp, "reply.txt")
            with open(schema, "w", encoding="utf-8") as f:
                f.write(CLAUDE_CODE_SCHEMA)
            args = [command, "exec", "--ephemeral", "--skip-git-repo-check", "-s", "read-only",
                    "-C", tmp, "--output-schema", schema, "-o", reply_path, "--color", "never"]
            if model:
                args += ["-m", model]
            args.append("-")
            try:
                result = runner(args, input=f"{CLAUDE_CODE_SYSTEM}\n\n{prompt}", capture_output=True,
                                text=True, timeout=timeout, check=False)
            except FileNotFoundError as exc:
                raise LiveModelConfigError(f"Codex command not found: {command}") from exc
            except subprocess.TimeoutExpired as exc:
                raise LiveModelConfigError(f"Codex request timed out after {timeout:g}s") from exc
            for line in (getattr(result, "stderr", "") or "").splitlines():
                if line.startswith("model: "):
                    observed.add(line[len("model: "):].strip())
            if getattr(result, "returncode", 1):
                raise LiveModelConfigError(
                    f"Codex exited {result.returncode}: {(getattr(result, 'stderr', '') or '').strip()[-300:]}"
                )
            reply = ""
            if os.path.exists(reply_path):
                with open(reply_path, encoding="utf-8") as f:
                    reply = f.read().strip()
            if not reply:
                raise LiveModelConfigError("Codex returned no reply")
            return reply

    complete.observed_models = observed  # type: ignore[attr-defined]
    return complete
```

```python
    n: int, k: int, transport: Optional[Transport] = None, *, version: str = "live-fake",

    """M5: the live chain task with a `send-report` effect torn by the crash at step `k`.
```

```python
"""M5 calibration: a model's own success rate on the task with no injected failure."""

from __future__ import annotations

import tempfile
from typing import Callable

from .scenario import run_reference

ELIGIBLE_RATE = 0.80
MIN_COMPLETED = 9


def run_calibration(scenario, runs: int = 10, *, base_factory: Callable[[], str] = tempfile.mkdtemp) -> dict:
    """Run the uncrashed task `runs` times; a run that raises counts as not completed."""
    successes = completed = 0
    errors: list[str] = []
    for _ in range(runs):
        try:
            outcome = run_reference(scenario, base_factory())
        except Exception as exc:  # noqa: BLE001 — a transport error is recorded, not fatal
            errors.append(f"{type(exc).__name__}: {exc}"[:300])
            continue
        completed += 1
        successes += int(bool(outcome.success))
    rate = successes / completed if completed else 0.0
    return {
        "runs": runs,
        "completed": completed,
        "successes": successes,
        "errors": errors,
        "calibration_rate": rate,
        "eligible": completed >= MIN_COMPLETED and rate >= ELIGIBLE_RATE,
    }
```

```python
CAPABILITY_MARGIN = 0.10
MAX_LOST_FRACTION = 0.10
GATE_MODELS = ("claude", "codex")


def verdict_c1_capability(summary: dict, calibration_rate: float) -> dict:
    """M5 capability-matched C1: recovery judged against the model's own uncrashed success rate.

    Unlike the strict `verdict_c1` (B3 must succeed in every repetition), B3's success rate must be
    within `CAPABILITY_MARGIN` of the calibration rate and at least B0's. Tax (success-conditioned,
    no overlap) and regression checks are unchanged. Pre-registered for M5; do not edit thresholds.
    """
    b0, b3 = summary.get("B0"), summary.get("B3")
    if not b0 or not b3 or b0["n"] == 0 or b3["n"] == 0:
        return {"claim": "C1-capability", "supported": False, "checks": {},
                "reason": "no fired B0/B3 cells to compare"}
    if b0.get("n_success", 0) == 0:
        return {"claim": "C1-capability", "supported": False, "checks": {},
                "reason": "B0 never completed the recovery, so it has no cost-of-recovery to compare (AP-0048)"}
    b3_rate, b0_rate = b3["task_success"].mean, b0["task_success"].mean
    checks = {
        "b3_within_capability": b3_rate >= calibration_rate - CAPABILITY_MARGIN,
        "b3_at_least_b0_success": b3_rate >= b0_rate,
        "tax_no_overlap": b3["recovery_tax"].max < b0["recovery_tax"].min,
        "no_regression_at_least_b0": b3["no_regression"].mean >= b0["no_regression"].mean,
    }
    reason = (f"calibration {calibration_rate:.2f}; B3 success {b3_rate:.2f} vs B0 {b0_rate:.2f}; "
              f"B3 tax max {b3['recovery_tax'].max:.2f} vs B0 tax min {b0['recovery_tax'].min:.2f}; "
              f"no-regression B3 {b3['no_regression'].mean:.2f} vs B0 {b0['no_regression'].mean:.2f}; "
              f"failed: {[k for k, ok in checks.items() if not ok] or 'none'}")
    return {"claim": "C1-capability", "supported": all(checks.values()), "checks": checks, "reason": reason}


def verdict_c3_live(summary: dict) -> dict:
    """M5 live C3: the WAL (B3) never duplicates the torn effect; without it (B0) it does."""
    b0, b3 = summary.get("B0"), summary.get("B3")
    if not b0 or not b3 or b0["n"] == 0 or b3["n"] == 0:
        return {"claim": "C3-live", "supported": False, "reason": "no fired B0/B3 cells"}
    b3_dup, b0_dup = b3["effect_duplicates_total"], b0["effect_duplicates_total"]
    supported = b3_dup == 0 and b0_dup >= 1
    return {"claim": "C3-live", "supported": supported,
            "reason": f"B3 duplicates {b3_dup} (must be 0); B0 duplicates {b0_dup} (must be >= 1)"}


def verdict_v1_gate(per_model: dict) -> dict:
    """M5 v1.0 gate over both models (pre-registered): INCONCLUSIVE / GO / NO-GO."""
    missing = [m for m in GATE_MODELS if m not in per_model]
    if missing:
        return {"decision": "INCONCLUSIVE", "reason": f"missing model results: {missing}"}
    for name in GATE_MODELS:
        m = per_model[name]
        if not m["eligible"]:
            return {"decision": "INCONCLUSIVE", "reason": f"{name} ineligible at calibration"}
        if m["planned_cells"] and m["lost_cells"] / m["planned_cells"] > MAX_LOST_FRACTION:
            return {"decision": "INCONCLUSIVE",
                    "reason": f"{name} lost {m['lost_cells']}/{m['planned_cells']} planned cells (> 10%)"}
    failed = [f"{name}:{claim}" for name in GATE_MODELS for claim in ("c1", "c3")
              if not per_model[name][claim]["supported"]]
    if failed:
        return {"decision": "NO-GO", "reason": f"not supported: {failed}"}
    return {"decision": "GO", "reason": "C1 (capability-matched) and C3 supported on both models"}
```

```python
"""M5 — the pre-registered v1.0-gate live study (AP-0055/AP-0056).

Per model: calibration (uncrashed), then the chain study with a torn `send-report` effect at each
crash step, B0 vs B3, `repeats` times. Records go to results/m5/<label>.json; `compute_gate` applies
the pre-registered gate. Live use is gated by `m5_preregister.verify()` in `main`.
"""

from __future__ import annotations

try:
    import _bootstrap  # noqa: F401
except ImportError:
    pass

import json
import os
import sys

from benchmarks.scenarios import build_live_transport, live_chain_effect_scenario, live_chain_scenario
from cairn.eval.baselines import ColdRestart, RGR
from cairn.eval.calibration import run_calibration
from cairn.eval.runner import (
    aggregate_repeated, run_repeated, verdict_c1, verdict_c1_capability, verdict_c3_live, verdict_v1_gate,
)

BASELINES = 2  # B0, B3


def load_protocol(path: str = "results/m5/protocol.json") -> dict:
    with open(path, encoding="utf-8") as f:
        return json.load(f)


def _jsonable(stats: dict) -> dict:
    out = {}
    for name, row in stats.items():
        out[name] = {k: (vars(v) if hasattr(v, "mean") else v) for k, v in row.items()}
    return out


def run_m5_model(label: str, protocol: dict, *, transport=None, out_dir: str = "results/m5") -> dict:
    cfg = protocol["models"][label]
    n, steps, repeats = protocol["n"], list(protocol["steps"]), protocol["repeats"]
    planned = len(steps) * BASELINES * repeats
    if transport is None:
        os.makedirs("benchmarks/transcripts", exist_ok=True)
        transport = build_live_transport(
            cfg["model"], provider=cfg["provider"], max_calls=protocol["max_calls"],
            transcript_path=f"benchmarks/transcripts/m5-{label}.jsonl",
        )
    record = {"label": label, "provider": cfg["provider"], "model": cfg["model"],
              "planned_cells": planned}
    record["calibration"] = run_calibration(live_chain_scenario(n, transport), runs=protocol["calibration_runs"])
    record["study_run"] = bool(record["calibration"]["eligible"])
    reports, errors, skipped, errored_repeats = [], [], 0, 0
    if record["study_run"]:
        for k in steps:
            run = run_repeated(
                live_chain_effect_scenario(n, k, transport), steps=[k],
                baselines=[ColdRestart(), RGR()], repeats=repeats,
                on_error=lambda i, exc: errors.append(f"k={k} repeat {i}: {type(exc).__name__}: {exc}"[:300]),
            )
            reports.extend(run.reports)
            skipped += run.skipped
            errored_repeats += run.errored
    record["lost_cells"] = errored_repeats * BASELINES if record["study_run"] else planned
    record["skipped_cells"] = skipped
    record["fired_cells"] = len(reports)
    record["errors"] = errors[:20]
    by: dict = {}
    for r in reports:
        by.setdefault(r.baseline, []).append(r)

    class _Run:  # minimal RepeatedRun-shaped view for aggregate_repeated
        pass

    view = _Run()
    view.reports = reports
    stats = aggregate_repeated(view) if reports else {}
    record["stats"] = _jsonable(stats)
    cal_rate = record["calibration"]["calibration_rate"]
    record["c1"] = verdict_c1_capability(stats, cal_rate)
    record["c1_strict"] = {k: v for k, v in verdict_c1(stats).items() if k in ("claim", "supported", "reason")} \
        if stats else {"claim": "C1", "supported": False, "reason": "no fired cells"}
    record["c3"] = verdict_c3_live(stats)
    record["eligible"] = record["calibration"]["eligible"]
    observed = getattr(transport, "observed_models", None)
    if observed:
        record["observed_models"] = sorted(observed)
    os.makedirs(out_dir, exist_ok=True)
    with open(os.path.join(out_dir, f"{label}.json"), "w", encoding="utf-8") as f:
        json.dump(record, f, indent=2, default=str)
    return record


def compute_gate(out_dir: str = "results/m5") -> dict:
    per_model = {}
    for label in ("claude", "codex"):
        path = os.path.join(out_dir, f"{label}.json")
        if os.path.exists(path):
            with open(path, encoding="utf-8") as f:
                per_model[label] = json.load(f)
    gate = verdict_v1_gate(per_model)
    with open(os.path.join(out_dir, "gate-verdict.json"), "w", encoding="utf-8") as f:
        json.dump(gate, f, indent=2)
    return gate


def main(argv: list[str]) -> int:
    from benchmarks.m5_preregister import verify

    problems = verify()
    if problems:
        print("refusing to run: pre-registration mismatch:\n  " + "\n  ".join(problems))
        return 2
    protocol = load_protocol()
    if argv and argv[0] == "gate":
        print(json.dumps(compute_gate(), indent=2))
        return 0
    label = argv[0] if argv else ""
    if label not in protocol["models"]:
        print(f"usage: python benchmarks/m5_study.py <{'|'.join(protocol['models'])}|gate>")
        return 2
    rec = run_m5_model(label, protocol)
    print(json.dumps({k: rec[k] for k in ("label", "eligible", "fired_cells", "lost_cells", "c1", "c3")},
                     indent=2, default=str))
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

```python
"""M5 pre-registration (AP-0054): freeze protocol + verdict code hashes before any live call."""

from __future__ import annotations

import hashlib
import json
import os
import subprocess
import sys
from datetime import datetime, timezone

FROZEN_FILES = [
    "results/m5/protocol.json",
    "src/cairn/eval/runner.py",
    "src/cairn/eval/calibration.py",
    "src/cairn/eval/scenario.py",
    "src/cairn/model_live.py",
    "benchmarks/scenarios.py",
    "benchmarks/m5_study.py",
]
PREREG = "results/m5/preregistration.json"


def _sha(path: str) -> str:
    with open(path, "rb") as f:
        return hashlib.sha256(f.read()).hexdigest()


def snapshot(root: str = ".") -> dict:
    return {rel: _sha(os.path.join(root, rel)) for rel in FROZEN_FILES}


def write_preregistration(root: str = ".") -> dict:
    try:
        commit = subprocess.run(["git", "-C", root, "rev-parse", "HEAD"], capture_output=True,
                                text=True, check=False).stdout.strip() or None
    except FileNotFoundError:
        commit = None
    record = {"files": snapshot(root), "git_commit": commit,
              "created_utc": datetime.now(timezone.utc).isoformat()}
    path = os.path.join(root, PREREG)
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w", encoding="utf-8", newline="\n") as f:
        json.dump(record, f, indent=2)
        f.write("\n")
    return record


def verify(root: str = ".") -> list[str]:
    path = os.path.join(root, PREREG)
    if not os.path.exists(path):
        return [f"no preregistration at {PREREG}"]
    with open(path, encoding="utf-8") as f:
        frozen = json.load(f)["files"]
    problems = []
    for rel in FROZEN_FILES:
        full = os.path.join(root, rel)
        if not os.path.exists(full):
            problems.append(f"{rel}: missing")
        elif rel not in frozen or _sha(full) != frozen[rel]:
            problems.append(f"{rel}: hash differs from preregistration")
    return problems


if __name__ == "__main__":
    if sys.argv[1:] == ["write"]:
        print(json.dumps(write_preregistration(), indent=2))
    else:
        problems = verify()
        print("OK" if not problems else "\n".join(problems))
        sys.exit(1 if problems else 0)
```
